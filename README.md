# BuddyBuddy

Find people to build side projects with. Post a project with the roles and skills you need, collect applications through a custom form, and share contact info once you accept someone.

> 🚧 Early development. See [docs/roadmap.md](docs/roadmap.md) for progress.

## Tech
Next.js 16 (App Router) · TypeScript · Neon Postgres + Drizzle · Better Auth (GitHub, Google) · Tailwind CSS + shadcn/ui · Vitest · GitHub Actions · Vercel

## Getting started
```bash
npm install
npm run dev    # http://localhost:3000
```
